# Sona

Sona is a web based instrument built with the Reactronica library.
The mobile friendly interface can be used to practice playing different scales, or as an on the go tuner for your instrument and your voice.

The Reactronica library utilizes Tone.js which is built on top of the the Javascript api for creating   AudioContext in the web browser.

Find the app deployed at [here](https://sona-sjnn.onrender.com)
