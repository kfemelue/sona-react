# Sona

## Objective 

Sona is a web based instrument built with the Reactronica library.
The mobile friendly interface can be used to practice playing different scales on a synthesizer, or as an on the go tuner for your instrument and your voice.

## Stack

- Client: React (Javascript/node) with Vite as a build tool
- Key Integrations:
    - The Reactronica library, which utilizes Tone.js and the Javascript API for creating AudioContext in the browser.

Find the app deployed at [here](https://sona-sjnn.onrender.com)
